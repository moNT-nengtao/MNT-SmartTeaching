# MNT-SmartTeaching 前端文件目录设计

> 技术栈：Vue3 + Vite + Element Plus + ECharts + Pinia + Vue Router
> 部署：构建后 `dist/` 目录交由 Nginx 托管

---

## 一、整体目录结构

```
smart-teaching-web/
├── public/
│   └── favicon.ico
├── src/
│   ├── api/                  # 接口请求层（与后端一一对应）
│   ├── assets/               # 静态资源
│   │   ├── images/
│   │   └── styles/
│   ├── components/           # 全局公共组件
│   │   └── Layout/           # 三段式布局组件
│   ├── router/               # 路由配置 + 权限守卫
│   ├── store/                # Pinia 状态管理
│   ├── utils/                # 工具函数
│   ├── views/                # 页面视图（按业务模块分目录）
│   ├── App.vue
│   └── main.js
├── .env.development          # 开发环境变量
├── .env.production           # 生产环境变量
├── vite.config.js            # Vite 构建配置（含代理）
├── nginx.conf                # Nginx 部署配置
├── package.json
└── index.html
```

## 二、src 下各目录详解

### 2.1 api/ — 接口请求层

每个文件对应一个业务域，统一从 `utils/request.js` 导入 axios 实例。

| 文件 | 职责 | 被哪些页面调用 |
|------|------|----------------|
| `request.js` | axios 实例封装：baseURL、请求拦截器（注入JWT）、响应拦截器（统一错误处理、401跳转登录） | 被所有其他 api 文件 import |
| `auth.js` | 登录、登出、获取用户信息、修改密码 | `views/login/index.vue`、`views/user/profile.vue` |
| `user.js` | 用户增删改查、禁用/启用、角色分配、批量导入 | `views/user/index.vue`（管理员） |
| `org.js` | 学院/专业/班级三级 CRUD、级联查询、批量导入导出 | `views/org/index.vue` |
| `course.js` | 课程管理、排课增删改查、排课冲突校验、课表导出 | `views/course/list.vue`、`views/course/schedule.vue` |
| `selection.js` | 选课开放时间设置、选课/退课、选课名单、剩余名额、热门预警 | `views/selection/manage.vue`、`select.vue`、`my.vue` |
| `score.js` | 成绩录入/修改/批量导入、成绩查询、成绩统计、异常筛查 | `views/score/entry.vue`、`query.vue`、`stats.vue` |
| `notice.js` | 公告发布/编辑/撤回/置顶、已读未读、通知搜索 | `views/notice/list.vue`、`publish.vue` |
| `schedule.js` | 周课表数据、课程颜色设置、课程收藏、课程备忘、上课提醒 | `views/schedule/index.vue` |
| `qa.js` | 问题列表（按课程分区）、问题发布（匿名/实名）、问题详情、回复、点赞、置顶、标签 | `views/qa/list.vue`、`detail.vue`、`publish.vue` |
| `ai.js` | AI知识点答疑、AI作业评语生成、AI学业分析建议、剩余次数查询 | `views/ai/index.vue` |
| `attendance.js` | 生成动态签到码、学生签到提交、考勤统计、考勤报表 | `views/attendance/teacher.vue`、`student.vue` |
| `warning.js` | 预警列表、预警详情、预警报告导出 | `views/warning/list.vue`、`report.vue` |
| `evaluation.js` | 提交评价、查看评价、教师评分榜单、评价统计 | `views/evaluation/student.vue`、`teacher.vue`、`ranking.vue` |
| `dashboard.js` | 管理员全局统计、教师授课数据、学生学业数据（雷达图/绩点趋势） | `views/dashboard/admin.vue`、`teacher.vue`、`student.vue` |

### 2.2 assets/

| 文件/目录 | 职责 |
|-----------|------|
| `images/` | logo、默认头像、空状态插图等静态图片 |

### 2.3 components/ — 公共组件

| 文件 | 职责 | 被谁使用 |
|------|------|----------|

| `Layout/Sidebar.vue` | 侧边栏菜单，**根据 `store/user.js` 中的 role 动态渲染不同菜单** | Layout/index.vue |
| `Layout/Header.vue` | 顶部栏：用户头像/下拉菜单、未读通知角标（调用 `notice.js`）、当前时间 | Layout/index.vue |

### 2.4 router/

| 文件 | 职责 | 关键关联 |
|------|------|----------|
| `index.js` | ① 定义路由表，按角色分三组（admin/teacher/student），全部嵌套在 Layout 下；② 全局前置守卫：校验 token → 获取用户角色 → 动态添加对应路由 → 无权限重定向；③ 登录页为公开路由 | 依赖 `store/user.js` 获取角色和 token；依赖 `utils/permission.js` 判断路由权限 |

### 2.5 store/ — Pinia

| 文件 | 存储内容 | 被谁读写 |
|------|----------|----------|
| `user.js` | token、用户基本信息（id/name/role/avatar）、权限菜单列表；actions：login/logout/fetchUserInfo | 登录页写入；`router/index.js` 守卫读取；`Sidebar.vue` 读取角色渲染菜单；所有 api 请求通过 request.js 读取 token |
| `app.js` | 侧边栏折叠状态、主题色；actions：toggleSidebar | `Sidebar.vue`、`Header.vue` |

### 2.6 utils/

| 文件 | 职责 | 被谁使用 |
|------|------|----------|
| `request.js` | axios 封装（同 api/request.js，或 api 直接引用此文件） | 所有 api 文件 |
| `auth.js` | token 的 localStorage 存取封装 | `store/user.js`、`utils/request.js` |
| `permission.js` | 判断当前用户是否拥有某角色/某菜单权限 | `router/index.js` 守卫、`Sidebar.vue`、页面内按钮级权限控制 |
| `format.js` | 日期格式化、绩点计算、成绩等级转换 | 成绩页、课表页、预警页 |

## 三、文件关联关系总览

### 3.1 核心数据流（前端视角）

```
org/index.vue (学院专业班级)
    ↓ 提供组织架构数据
user/index.vue (用户分配到班级)
    ↓
course/list.vue (课程关联学院专业)
    ↓
course/schedule.vue (排课：教师+课程+班级+时间)
    ↓ 排课结果
selection/manage.vue (设置选课规则) → selection/select.vue (学生选课)
    ↓ 选课结果
schedule/index.vue (学生课表) ←── 排课 + 选课
    ↓
attendance/teacher.vue (生成签到码) → attendance/student.vue (学生签到)
    ↓ 考勤数据
score/entry.vue (教师录成绩)
    ↓ 成绩 + 考勤数据
dashboard/student.vue (雷达图/绩点趋势)
warning/list.vue (学业预警，后端定时扫描)
```

### 3.2 关键依赖链

1. **登录 → 权限 → 菜单 → 路由**：`login/index.vue` → `store/user.js`(存role/token) → `router/index.js`(守卫按role加路由) → `Sidebar.vue`(按role渲染菜单)
2. **请求鉴权**：所有 `api/*.js` → `utils/request.js`(请求拦截器从 `store/user.js` 取 token 注入 header)
3. **课表依赖**：`schedule/index.vue` 依赖排课(`course/schedule.vue`)和选课(`selection/select.vue`)两者的数据
4. **预警依赖**：`warning/` 展示的数据由考勤(`attendance/`) + 成绩(`score/`) + 作业（隐含在成绩/答疑中）联合触发，前端无直接写入
5. **评价跨模块**：`selection/select.vue` 的"往届评价预览"调用 `api/evaluation.js`；`evaluation/student.vue` 仅对已选且结课的课程开放
6. **AI助教双模式**：`ai/index.vue` 根据 `store/user.js` 的 role 自动切换学生/教师功能面板

### 3.3 公共组件复用

- `Layout/` 被所有业务页面通过路由嵌套复用
- `ChartCard.vue` 被 3 个 dashboard 页面和学生成绩统计复用
- `Pagination.vue` + `SearchForm.vue` 被所有列表型页面复用

## 四、Nginx 部署要点（nginx.conf）

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /usr/share/nginx/html/dist;
    index index.html;

    # Vue Router history 模式必须配置，否则刷新404
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 接口反向代理，前端 request.js baseURL 设为 /api
    location /api/ {
        proxy_pass http://localhost:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
}
```

- 前端 `vite.config.js` 中 `build.outDir = dist`，构建产物直接上传到 Nginx 的 html 目录
- `utils/request.js` 的 baseURL 生产环境设为 `/api`，通过 Nginx 反向代理到后端 SpringBoot（默认8080），避免跨域
