# 前端工程文件结构说明（Vue3 + Vite + Element Plus）

> 与《后端工程文件结构说明》配对阅读。前端按业务目录组织，与后端微服务的网关前缀一一对应；微服务化对前端几乎是"零感知"的——所有请求走 `/api` 前缀，由 Vite 开发代理 / Nginx 生产代理转发到网关，前端不需要关心服务拆分。

## 一、顶层结构

```
smart-teaching-web/
├── src/                    # 源码（核心）
├── public/                 # 静态资源（不经构建直接拷贝）
├── dist/                   # 构建产物（gitignore，不入库）
├── index.html              # 页面入口（挂载 #app）
├── package.json            # 依赖与脚本（dev / build / preview）
├── package-lock.json
├── vite.config.js          # 构建与开发代理配置
├── .env.development        # 开发环境变量
├── .env.production         # 生产环境变量
├── nginx.conf / build.bat  # 历史单体遗留的本地配置（已被 scripts/ 脚本体系取代）
└── node_modules/           # 依赖（不入库）
```

## 三、关键文件说明

### 1. vite.config.js —— 开发代理是"开发模式微服务路由"的实现

```js
server: {
  port: 5173,
  proxy: {
    '/api': { target: 'http://localhost:8080', changeOrigin: true },   // 开发时转发到网关
    '/files': { target: 'http://localhost:8080', changeOrigin: true }  // 静态文件转发
  }
},
resolve: { alias: { '@': path.resolve(__dirname, 'src') } }            // @ 别名
build: { outDir: 'dist', ... }                                          // 构建产物配置
```

### 2. .env 环境变量 —— 微服务化"前端零改动"的关键

```ini
# .env.development
VITE_APP_BASE_API = /api
# .env.production
VITE_APP_BASE_API = /api        # 生产走 Nginx 同源代理，同样只写 /api
```

`BASE_API` 在开发 / 生产都是 `/api`（相对路径）：开发由 Vite 代理到网关，生产由 Nginx 代理到网关，**前后端分离但前端不用感知微服务存在**。

### 3. utils/request.js —— 与后端约定对接

- 请求拦截：从 `store/user` 取 token，自动加 `Authorization: Bearer xxx`
- 响应拦截：`code === 1` 成功；`code === 0` 弹错误；`code === 401` 弹窗引导重新登录
- `responseType === 'blob'` 直接返回（导出文件下载场景）
- 超时 15s

### 4. router/index.js + utils/permission.js —— 三角色路由

路由按 `adminRoutes / teacherRoutes / studentRoutes` 分组，meta 标记 `roles`；登录后根据角色动态注入路由，未登录访问受保护页重定向 `/login`，无权限重定向对应角色首页。

## 四、前端模块 ↔ 后端服务 ↔ 网关前缀 对应表

| 前端 api 模块 | 前端页面 (views) | 网关前缀 | 后端服务 |
|---|---|---|---|
| auth.js | login | `/api/auth/**` | uaa-service |
| user.js / org.js | user / org | `/api/user/**`、`/api/org/**` | uaa-service |
| course.js / schedule.js | course / schedule | `/api/course/**`、`/api/schedule/**` | course-service |
| selection.js / score.js | selection / score | `/api/selection/**`、`/api/score/**` | selection-score-service |
| attendance.js | attendance/teacher、student | `/api/attendance/**` | attendance-service |
| warning.js | warning/list、report | `/api/warning/**` | warning-service |
| ai.js | ai | `/api/ai/**`、`/api/ollama/**` | ai-service |
| dashboard.js | dashboard/admin、teacher、student | `/api/dashboard/**` | analysis-service |
| homework.js / notice.js / qa.js / evaluation.js | 对应 views | `/api/homework|notice|qa|evaluation/**` | teaching-service |

## 五、一次请求链路（前端视角）

```
页面组件(views) → api/xxx.js → utils/request.js(axios, 注入 JWT)
→ 同源 /api 请求 → 开发: Vite 代理 → 网关 8080
                     生产: Nginx 代理 → 网关 8080
→ 网关按前缀路由 → 对应微服务 → 响应原路返回 → 拦截器统一处理
```
