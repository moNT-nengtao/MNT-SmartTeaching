# MNT Smart Teaching 前后端接口文档

> 盘点范围：`nginx-1.31.3/smart-teaching-web/src/api` 与 `smart-teaching-backend/src/main/java/com/smartteaching/controller`。
>
> 盘点日期：2026-08-20。
>
> 本文只记录当前源码事实，不对后端做任何修改。标记为“未实现”或“未核实”的字段不能直接作为后端契约使用。

## 1. 通用约定

### 1.1 请求前缀

前端 `VITE_APP_BASE_API=/api`，因此 API 文件中的 `/auth/login` 实际请求地址为：

```text
/api/auth/login
```

登录后请求拦截器自动添加：

```http
Authorization: Bearer <JWT>
```

### 1.2 普通响应

后端统一返回：

```json
{
  "code": 1,
  "msg": null,
  "data": {}
}
```

- `code=1`：成功。
- `code=0` 或其他非 1：失败。
- `msg`：错误信息。
- `data`：业务数据；无数据的成功响应通常为 `null`。

### 1.3 分页响应

用户列表使用：

```json
{
  "total": 0,
  "pages": 0,
  "current": 1,
  "size": 10,
  "records": []
}
```

字段类型均为 Java `Long`，前端 JavaScript 中按 number 使用时注意大整数精度。

### 1.4 文件请求

文件上传必须使用 `multipart/form-data`，文件字段名必须与后端 `@RequestParam` 或 `@RequestPart` 完全一致。下载接口返回二进制，前端请求配置为 `responseType: 'blob'`。

## 2. 后端已实现接口

当前后端 Controller 实际提供 20 个接口，只有以下四个模块可以依据后端源码确认完整字段：`auth`、`dashboard`、`org`、`user`。

## 3. 认证模块 `/api/auth`

### 3.1 登录

```http
POST /api/auth/login
Content-Type: application/json
```

请求体 `UserLoginDTO`：

| 字段 | Java 类型 | 必填 | 说明 |
|---|---|---:|---|
| `username` | String | 是 | 非空 |
| `password` | String | 是 | 非空 |
| `role` | String | 否 | 登录角色；若传入，必须与用户角色匹配 |
| `code` | String | 否 | 后端 DTO 有此字段，当前登录业务未使用 |
| `rememberMe` | Boolean | 否 | 后端 DTO 有此字段，当前登录业务未使用 |

响应 `data` 为 `UserLoginVO`：

| 字段 | 类型 |
|---|---|
| `token` | String |
| `id` | Long |
| `username` | String |
| `realName` | String |
| `gender` | Integer |
| `email` | String |
| `phone` | String |
| `avatar` | String |
| `role` | String |
| `status` | Integer |
| `classId` | Long |
| `collegeId` | Long |
| `majorId` | Long |
| `lastLoginTime` | LocalDateTime |

### 3.2 获取当前用户信息

```http
GET /api/auth/userInfo
Authorization: Bearer <JWT>
```

无请求参数。响应 `data` 为 `UserLoginVO`，`token` 通常为空，因为此接口不会重新生成 token。

### 3.3 登出

```http
POST /api/auth/logout
Authorization: Bearer <JWT>
```

无请求体。成功时 `data=null`。

### 3.4 修改密码

```http
PUT /api/auth/changePassword
Content-Type: application/json
Authorization: Bearer <JWT>
```

请求体：

| 字段 | 类型 | DTO 标注必填 |
|---|---|---:|
| `oldPassword` | String | 是 |
| `newPassword` | String | 是 |

成功时 `data=null`。注意：Controller 当前参数没有 `@Valid`，DTO 上的声明式非空校验不一定实际触发。

### 5.9 班级移出学生

单个移出和一键移出共用同一个接口，单个学生也必须以数组传递：

```http
POST /api/org/students/remove
Content-Type: application/json
```

请求体：

```json
{
  "ids": [1001, 1002]
}
```

字段约定：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `ids` | Long[] | 是 | 要移出班级的学生 ID；单个操作也传 `[studentId]` |

前端函数为 `removeStudentsFromClass(ids)`：

- 单个：`removeStudentsFromClass([student.id])`
- 一键：`removeStudentsFromClass(studentList.map(student => student.id))`

后端只需要从请求体读取完整 `ids` 数组并执行业务处理。当前仓库后端尚未提供该 Controller，响应格式需以后端实际实现为准；前端按统一成功响应 `code=1` 处理。

| 字段 | 类型 | 必填 | 约束 |

| `email` | String | 否 | Email 格式 |
| `avatarFile` | MultipartFile | 否 | 头像文件 |

成功响应 `data="新增用户成功"`。

### 6.3 编辑用户

```http
PUT /api/user
Content-Type: multipart/form-data
```

字段同新增，但：

- `id` 为 Long，必填；
- `username` 编辑时不要求必填；
- `password` 可选；
- `avatarFile` 可选。

成功时 `data=null`。

### 6.4 删除用户

```http
DELETE /api/user/{id}
Authorization: Bearer <JWT>
```

`id` 在 Controller 中为 String，后端随后按用户 ID 查询。不能删除当前登录用户，也不能删除 admin 用户。成功时 `data=null`。

### 6.5 启用/禁用用户

```http
PUT /api/user/{id}/status
Authorization: Bearer <JWT>
```

后端实际只读取 path `id` 和 Authorization，不读取前端传入的 `status` query；服务层根据当前状态自动切换。成功时 `data=null`。

### 6.6 批量导入用户

```http
POST /api/user/batchImport
Content-Type: multipart/form-data
```

必须使用文件字段名：

```text
file
```

Excel 列名必须是：

```text
账号、姓名、密码、性别、角色、手机号、邮箱、学院ID、专业ID、班级ID
```

成功响应 `data` 为字符串：`批量导入成功，共导入 N 条数据`。

## 8. 已确认的不一致与风险

1. 用户新增、编辑：前端 API 以普通 `data` 发送，后端实际要求 `multipart/form-data`，并支持 `avatarFile`。
2. 用户批量导入：后端要求 multipart 字段名 `file`，前端 API 未保证该字段名。
3. 用户启用/禁用：前端发送 `status`，后端忽略该 query，实际执行 toggle。
4. 用户角色分配：前端声明 `/user/{id}/role`，后端不存在。
5. 组织批量导入/导出：前端声明接口，后端不存在。
6. 组织学生移出：前端已统一调用 `POST /org/students/remove`，请求体为 `{ ids: Long[] }`；后端仍需要提供对应 Controller。
7. 组织列表 API 未暴露后端支持的 `isSelect` 参数。
8. 所有 AI、考勤、课程、评价、公告、答疑、课表、成绩、选课、预警 HTTP 接口目前只有前端声明，后端 Controller 未提供。
9. 仪表盘接口字段已确定，但当前返回值是 0 和空数组，不能当作真实统计结果。
10. `id` 在不同接口中存在 Long、String 两种后端声明，前端不要默认所有 ID 都可以无损转为 JavaScript number。
